TOON Paste Options

Customize how clipboard JSON is encoded into TOON format. These options control indentation, delimiters, and key folding behavior.

Keyboard Shortcut

To set your keyboard shortcut, click the button below or visit chrome://extensions/shortcuts

Encoding Options

Number of spaces per indentation level (default: 2)
Delimiter for array values and tabular rows. Tab often tokenizes better for LLMs.
Enable key folding to collapse wrapper chains into dotted paths (e.g., user.profile.name)
Maximum number of segments to fold when key folding is enabled (0 = unlimited)
